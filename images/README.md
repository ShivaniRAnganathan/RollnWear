# Photos

Each colour in `stock.json` has an `image` path, or `null` for a Photo coming soon card. Paths are relative, for example `images/game-night--black.webp`.

Photos are 4:5, cropped to the chest print, and saved as WebP under 150KB. Replace a file with the same name, or add a new one and set `image` in `stock.json`.
