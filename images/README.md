# Photos

The shop looks up each picture from the `image` field in `stock.json`. Paths are relative, for example `images/game-night.jpg`. Leave `image` as `null` to show a name card instead of a photo.

Swap a photo by replacing the file, keeping the same name. A useful size is about 720 pixels wide, saved as JPEG, ideally under 80KB. The page crops photos to a tall frame, so keep the print near the upper half.

Add a missing photo by saving it under the filename below, then set that item's `image` in `stock.json` to the same path.

Some photos show a tee colour that the stock line does not name. They are still the photos for that design. Do not point a differently coloured stock line at a photo of another colour. There is no white Board Game Components photo and no yellow Power to the Meeple photo in this set, so those stay name cards until you add one.

`images/logo-circle.png` is the header mark. `images/logo.png` is the full logo on a dark background. `images/og.jpg` is the picture WhatsApp and Instagram use in link previews. If you replace `og.jpg`, keep it at 1200×630.

Do not redraw or retype the wordmark inside the logo. If you need it larger than the header, ask for a high-resolution PNG or SVG.
