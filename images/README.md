# Photos

Each colour in `stock.json` has an `image` path, or `null` for a Photo coming soon card. Paths are relative, for example `images/game-night--black.webp`.

Photos are 4:5, cropped to the chest print, and saved as WebP under 150KB. They come from the owner's Hextasy product pages. A collage is cropped to one tee. If the stocked colour is not in those photos, the closest photo of the same design is used and the swatch keeps the stocked colour. The artwork is not recolored.
